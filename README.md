# 以日为鉴 · 衰退时代普通人生存指南（新版 · 作者判断版）

**在线阅读：https://mirror.strangeyu.xyz**

一份单文件 HTML 网页知识库：以分析师 Boden《以日为鉴：衰退时代生存指南》全书 5 篇 15 章及其 B 站书外视频为叙事底稿与覆盖清单，逐条用 **35 位中日及国际经济学家、学者**的研究做补充与对冲，结合截至 **2026 年 10 月**的最新数据，由作者直接给出"结论 + 置信度 + 依据 + 行动"。

> Boden 是被审视的对象，不是裁判。他书中不严谨的外推，在多视角对照中被修正；我们综合各方判断后直接给结论，而不是把选择题丢给读者。

## 方法论与写作纪律

- **作者权威化**：综合学者判断与最新数据后直接下结论、给动作，不让读者在对立观点间自行选边。
- **三级置信度**：`[高可信·已查证]` / `[推演·中可信]` / `[推演·低可信]`，每条结论标注证据强度。
- **来源可追溯**：正文以上标 `[n]` 对应文末 29 条参考资料（专著、学术论文、官方统计、权威媒体访谈）。
- **数据纪律**：优先 2026 年、至少 2025 年数据；凡学者/机构估算值均明确标注"估算（估算方法来源于 xxx）"，官方数据发布后更新；不同口径并排呈现（如养老金"基金池总量"与"个人账户结构"两套口径）。
- **风险写实**：区分事实与推演，不回避坏消息，也不给出超出证据的恐慌性结论；每个风险判断都配个人可执行的解法。

## 内容结构

引子 + 七篇 + 结语 + 参考资料：

1. **第一篇** 中日对照总判断（哪些相同、哪些不同、哪些角度会重蹈覆辙）
2. **第二篇** 宏观周期与政策对冲（资产负债表衰退之争、情形 A/B 的作者结论）
3. **第三篇** 工作与职业（就业冰河世代、学历贬值、读研/读博决策、医生/教师/公务员、中年返贫）
4. **第四篇** 资产、房子与婚姻（买房租房、资产配置、婚姻作为长期合伙）
5. **第五篇** 医疗与养老（医药行业、多支柱养老、**个人账户空账**专题）
6. **第六篇** 机会在哪（新产业、出海，中立呈现）
7. **第七篇** 分人群落地动作总表（应届生 / 中年高房贷 / 中年低负债 / 自由职业 / 临近退休）
8. **结语** 在存量时代做跨周期玩家
