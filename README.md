## 这是什么

灵感源自财经分析师 Boden《以日为鉴：衰退时代生存指南》（开明出版社，2025 年 8 月）的**独立增补作品，非原书官方版本**。原书最有价值的贡献，是把日本 1990 年代之后的职业史（就业冰河期、学历贬值、考公热、教师与医生、医药寒冬、理工科劝退、全民出海）讲成可以对照个体命运的具体经验；全书 5 篇 15 章，不涉及宏观理论——"资产负债表""辜朝明""通缩""降杠杆"在 12.6 万字里均为 0 次。它只有一家之言，最要紧的那步外推（日本 1994 年后的出海 → 中国 2024 年）前提没有逐条检验，数据也停留在 2024–2025 年。

本增补版以原书 5 篇 15 章及作者 B 站书外视频为叙事底稿与覆盖清单（书内、书外、误传三种来源在正文里分别标注，见页面引子的"引用纪律"），逐条用 **20 余位中日及国际经济学家、学者**的研究做补充与对冲，结合截至 **2026 年 10 月**的最新数据，直接给出"结论 + 置信度 + 依据 + 行动"。

相比原书，增补版新增：① 20 余位学者观点逐条对冲并标注来源；② 三级置信度与证伪信号；③ 数据更新至 2026 年 10 月（估算注明方法来源）；④ 养老金个人账户空账专题、医生/教师/公务员职业分析、出海与新产业、五类人群决策树；⑤ 对"人口宿命论""个体无力论"等过度悲观外推的修正；⑥ 85 条可核查参考资料与开源页面。

> Boden 是被审视的对象，不是裁判。他书中不严谨的外推，在多视角对照中被修正；综合各方判断后直接给结论，而不是把选择题丢给读者。

## 方法论与写作纪律

- **作者权威化**：综合学者判断与最新数据后直接下结论、给动作，不让读者在对立观点间自行选边。
- **三级置信度**：`[高可信·已查证]` / `[推演·中可信]` / `[推演·低可信]`，每条结论标注证据强度。
- **来源可追溯**：正文以上标 `[n]` 对应文末 85 条参考资料（专著、学术论文、官方统计、权威媒体访谈）。
- **数据纪律**：优先 2026 年、至少 2025 年数据；凡学者/机构估算值均明确标注"估算（估算方法来源于 xxx）"，官方数据发布后更新；不同口径并排呈现（如养老金"基金池总量"与"个人账户结构"两套口径）。
- **风险写实**：区分事实与推演，不回避坏消息，也不给出超出证据的恐慌性结论；每个风险判断都配个人可执行的解法。

## 姊妹篇：高性价比人生指南 · 衰退时代补丁包

`patch.html` 是致敬 GitHub 开源项目 [HowToLiveBetter《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter)（CC BY 4.0）的独立增补作品。原指南 600 余条讲的是**正常时代**怎么活（怎么不早死、不浪费钱、不踩法律红线）；补丁包不重复这些，只做一件事——当经济进入下行周期，哪些"高性价比动作"要**升级、反转、新增、降级**，共 **41 条**。每条写明成本、换回什么、证据档（高可信·已查证 / 推演·中可信 / 推演·低可信）、适用人群与触发档位，并链回本页对应章节的完整论证。

- 在线：https://mirror.strangeyu.xyz/patch.html
- 用法：先读页首"情形 A / B"当前档位（这是随季度财政、物价、房地产数据滚动调整的活判断，以页面标注的判断时点为准）；标"两情形都做"的现在就做，标"仅 B 档加码"的等证伪信号出现再启动、信号消退即撤回。
- 宏观衰退无法做随机对照试验，证据口径沿用本指南的三级置信度，不含"做了就一定怎样"的保证。
- 配套 `patch-og.png`（1200×630 社交分享封面）。

## 内容结构

引子 + 七篇 + 结语 + 参考资料：

1. **第一篇** 中日对照总判断（哪些相同、哪些不同、哪些角度会重蹈覆辙）
2. **第二篇** 宏观周期与政策对冲（资产负债表衰退之争、情形 A/B 的作者结论）

5. **第五篇** 医疗与养老（医药行业、多支柱养老、**个人账户空账**专题）
6. **第六篇** 机会在哪（新产业、出海；含**普通人找外派岗的渠道清单（按可信度排序）**、**五种出海模式的风险量化**、**按能力对号的三条决策入口**与避坑清单）

## 读者批注

两页都接了读者批注层：选中正文任意一句 → 划线 → 写批注。**不用登录、不收集账号**，
提交的内容只有作者能看到，别人打开页面只会看到自己划过的（私有回显）。

- 前端 `annotate.js`（约 33 KB，无依赖）：高亮走 CSS Custom Highlight API，**不改动正文 DOM**，
  所以不影响目录、锚点跳转与 scroll spy。
- 后端 `worker/`（Cloudflare Worker + KV）：守 origin 白名单、限流、幂等去重，
  再用维护者凭据把批注代发到私有仓库的聚合 issue。详见 [`worker/README.md`](worker/README.md)。
- 锚点存"章节 + 章节内偏移 + 原片段 + 前后 40 字上下文"，正文改动后靠上下文匹配自愈（三级降级）。

## 读者交流（QQ 群 + 作者微信）

顶栏「分享」键旁边是一个常驻入口，点开是下拉栏（`qqgroup.js`，两页共用）：

- **加 QQ 群** —— 那一行直接写成「QQ：1130141971」，**点整行才跳转**；
- **加作者微信交流** —— 点那一行，二维码在菜单里展开，扫码或长按识别即可。

页脚另有一块同样的 QQ 群卡片做兜底。一键加群链接带的是**有时效的签名参数**（`authKey` / `data`），
所以页面上真正的兜底是**群号本身**：可选中、有一键复制按钮；链接哪天失效，复制群号去 QQ 里搜一样能进。
另外微信内置浏览器会拦 QQ 域名，检测到微信环境时那一行会直接换成「复制群号」，不让读者白点。

二维码不是从截图里裁的，是 `tools/wechat-qr-extract.py` **还原**出来的：截图的模块边长是非整数
（432px ÷ 37 模块 = 11.676px），按像素裁会带亚像素相位偏差、重绘后边缘发毛甚至扫不出；
脚本改成先反推模块网格（以「OpenCV 能否解码」为验收标准）再按原图配色重绘，
四周按规范补 4 模块静区，成品 720×720 / 约 4 KB。

## 技术形态

纯静态**单文件 HTML**（内联 CSS/JS，无构建、无追踪脚本），双击即可离线阅读；另有四个可选增强件：
`annotate.js`（批注）、`qqgroup.js`（顶栏 QQ 群 / 微信下拉入口）、`wechat-qr.png`（作者微信二维码）、
`og.png` / `patch-og.png`（1200×630 社交分享封面，缺失也不影响页面本身）。
可直接部署到 Cloudflare Pages / GitHub Pages / Vercel / Netlify 等任何静态托管。
